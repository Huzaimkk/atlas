# CV inbox

Drop your CV here to unblock Phase 2 (Profile Engine, `atlas-v2-spec1.md` §3).

**Accepted formats:** PDF, DOCX, or Markdown (`.pdf`, `.docx`, `.md`).

Drop the most current version only — if you add a new one, remove the old one so the ingest step doesn't have to guess which is authoritative. Anything placed here is picked up by the Phase 2 ingest job and parsed into a `ProfileSnapshot`; nothing in this folder is committed to git (see the root `.gitignore`).
